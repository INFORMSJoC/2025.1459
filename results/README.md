# Experimental results

- [paper_results](paper_results/README.md): reader-facing tables, figures, paper mapping and per-experiment summaries.
- [raw_results](raw_results/README.md): native solver measurements/logs, historical numerical sources and verification indexes.

`./scripts/run.sh refresh` rebuilds summaries. `./scripts/run.sh tables` and `figures` rebuild paper exports. These commands are run from the repository root and require no new solver experiments.
