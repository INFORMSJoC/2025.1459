# Repository revision — October 19, 2026

This revision addresses [the repository review](https://github.com/INFORMSJoC/2025.1459/pull/1#issuecomment-6253346491).

| Review point | Change |
|---|---|
| IJOC template and root layout | Added the journal banner, exact paper title and template-style sections with Cite first. The root now contains the main README, AUTHORS, LICENSE, CITATION.cff and the five recommended directories. | Results organization | Replaced `experiments` with `results/raw_results` and `results/paper_results`. Tables and figures are in `paper_results/tables_and_figures`; summaries are in `paper_results/experiments`. Native evidence and new attempts are under `raw_results`. |

| Data JSON | Moved required hash inventories and archive extraction indexes out of `data` to `scripts/config/data`, with a README explaining how each is used. |
| PDQP | Separated the original MIT license text into `src/competitors/PDQP/LICENSE`. |
| HPR variants | Recorded the authors' confirmation that all six variants were developed specifically for and used only in this project. |
| Dropbox | Retained the existing prepared-data link and extraction support while the editor considers hosting acceptability; no approval is claimed. External archives were not modified in this revision. |

## Validation of the revision

- Eight launcher/orchestration regression tests pass, including resume, interruption, guard failures, caller-relative paths containing spaces and split-archive extraction. Tests use clearly artificial inputs and simulated workers; no third-party data are needed by the tests.
- Scope checks preserve all 14 source groups, 365 HPR benchmark/curve cases, six source variants and 315 input representations (279 HPR inputs plus 36 explicit QAP inputs).
- All 1,129 previously packaged native/reference files are byte-for-byte unchanged.
- All 106 numerical result CSVs retain their values; raw-file path fields were relocated. All 4,226 archived solver rows and 365 historical HPR per-case records retain their numerical values.
- Paper table generation and all 13 grayscale PDFs regenerate from the new paths. Existing reported manuscript discrepancies remain unchanged.
- Existing external data paths resolve correctly: all 36 QAPLIB MAT files pass hash verification; QAPLIB and Restart-Sigma plans find their inputs. The two appendix methods plan without external data.
- Julia 1.10.4 with QPSReader parses the new author-created initialization-only QP as intended (two variables, one equality, diagonal Hessian). It is not a paper benchmark.
- Package checks cover local documentation links, input-list consistency, source dependency paths and release hashes.

The numerical solver kernels and benchmark settings are unchanged. Two legacy dataset-driver warmup paths and the JuMP competitor warmup now use the author-created support input, because the former third-party warmup files are no longer bundled. The unified HPR worker still warms up on the selected case. No new GPU benchmark experiments were run for this organization revision.

## Updated entry points

From the repository root, use `./scripts/run.sh check`, `./scripts/run.sh EXPERIMENT SOLVER`, and `./scripts/run.sh refresh`. Data acquisition is now required for MM, QAPLIB and Restart-Sigma; see the [data guide](../data/README.md). New downloads and local runs are excluded from Git and release ZIPs.
