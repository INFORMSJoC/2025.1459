# PDQP source used for paper reproduction

Use the `scripts/run.sh` launcher and the pinned `scripts/environments/PDQP/` environment. `scripts/solve_0.jl` is the sole retained command-line driver. Historical shell launchers and the obsolete nested manifest are excluded. The output-only patch omits primal/dual vector files; solver summaries and iteration logs remain. The numerical algorithm is unchanged.
