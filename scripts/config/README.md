# Execution settings and integrity metadata

This directory is for machine-readable configuration. Numerical measurements and native output have moved to [results/raw_results](../../results/raw_results/README.md).

| File | Purpose |
|---|---|
| `experiments.json` | HPR variant, parameters and selected input names; historical per-case measurements are stored separately in `hpr_case_results.json` under raw results |
| `reviewer_experiments.json` | Public experiment/solver mapping, tolerances, case identifiers and input hashes; archived numerical rows are stored separately in `archived_results.json` under raw results |
| `paper_scope.json` | Frozen case membership, checked against the HPR configuration |
| `SHA256SUMS.json` | Current distributed-file checksums, regenerated by `scripts/build_release.py`; generated summaries and user downloads/runs are excluded |
| [data](data/README.md) | Input verification hashes, legacy path aliases and archive extraction indexes |

The Appendix E numerical input is in [data/Appendix-Example](../../data/Appendix-Example/README.md). The manuscript result map is in [paper_results](../../results/paper_results/paper_result_map.csv).
