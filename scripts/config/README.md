# Execution settings and integrity metadata

This directory is for machine-readable configuration. Numerical measurements and native output are stored in [results](../../results/README.md).

| File | Purpose |
|---|---|
| `experiments.json` | HPR variant, parameters and selected input names; paper per-case measurements are linked by `reference_csv` to the corresponding native CSV |
| `experiment_catalog.json` | Public experiment/solver mapping, tolerances, case identifiers and input hashes; paper numerical rows are stored in the corresponding `paper_results/exp_*/solver_*/summary.csv` |
| `paper_scope.json` | Frozen case membership, checked against the HPR configuration |
| `SHA256SUMS.json` | Current distributed-file checksums, regenerated by `scripts/build_release.py`; generated summaries and user downloads/runs are excluded |
| [data](data/README.md) | Input verification hashes, legacy path aliases and archive extraction indexes |

The Appendix E numerical input is in [data/Appendix-Example](../../data/Appendix-Example/README.md). The manuscript result map is in [paper_results](../../results/paper_result_map.csv).
